**SportMind is not a collection of independent files. It is a connected reasoning system.**
This file is the map of all connections.

## The complete layer connection map

```
MACRO INTELLIGENCE feeds into:
  → All fan token demand signals (macro modifier applies universally)
  → Regulatory jurisdiction determines which tokens are accessible
  → Crypto cycle phase affects demand ceiling for all tokens
  → Institutional signals affect commercial intelligence

SPORT DOMAIN feeds into:
  → Pre-match adjusted score (primary signal)
  → Athlete intelligence weighting (which positions matter most
    depends on the sport domain system)
  → Referee and venue modifiers
  → FTP PATH_2 WIN probability

ATHLETE INTELLIGENCE feeds into:
  → Pre-match adjusted score modifier
  → FTP PATH_2 supply event magnitude
    (lower WIN probability = smaller expected burn pool)
  → Fan token demand signal
    (key player news affects demand independently of match prediction)
  → Post-match intelligence update
    (injury revelations change next-match athlete signal)

FAN TOKEN COMMERCIAL feeds into:
  → FTP PATH_2 mechanics (supply event calculation)
  → Demand signal baseline (token state determines base demand)
  → Governance signals (vote announcements affect community engagement)
  → Portfolio correlation (multiple tokens interact)

MARKET INTELLIGENCE feeds into:
  → CDI base for all tokens
  → Transfer window timing modifies athlete intelligence confidence
  → Seasonal patterns adjust demand baseline throughout year
  → Commercial state of club affects long-term demand ceiling

PSYCHOLOGICAL INTELLIGENCE feeds into:
  → Pre-match modifier (momentum, rivalry, pressure)
  → Post-match signals (how result affects next match)
  → Coaching intelligence (manager pressure affects decisions)
  → Fan token community sentiment (psychological momentum affects holder behaviour)

COACHING INTELLIGENCE feeds into:
  → Pre-match tactical modifier
  → New manager effect on results
  → Press conference signal weighting
  → Squad morale assessment

SCENARIO INTELLIGENCE feeds into:
  → Every signal where uncertainty is high enough to justify
    multiple scenario mapping
  → FTP PATH_2 supply event probability-weighted estimates
  → Regulatory outcome planning

TRAJECTORY INTELLIGENCE feeds into:
  → Medium-term demand estimates
  → State-space transition probabilities
  → Multi-horizon planning signals

BREAKING NEWS feeds into:
  → Immediate scenario map update
  → Athlete intelligence revision
  → Coaching intelligence update
  → Fan token demand signal adjustment

POST-MATCH INTELLIGENCE feeds into:
  → Form signal update for next match
  → FTP PATH_2 pool recalculation
  → Psychological modifier for next fixture
  → Press conference signal validation
```

## Signal priority hierarchy

```
LEVEL 1 — OVERRIDE (always wins — all other signals suspended):
  Macro override active
  Official integrity investigation confirmed
  CFTC enforcement action on token or protocol
  Smart contract emergency pause

LEVEL 2 — HIGH CONFIDENCE (win over Levels 3-5):
  Confirmed lineup (T-2h)
  Confirmed key player absence (official source)
  Confirmed match result
  Official regulatory enactment (Tier 1 source)

LEVEL 3 — STANDARD MODIFIERS (stack within caps):
  Pre-match sport domain signal
  Athlete intelligence
  Venue and weather modifiers
  Coaching intelligence

LEVEL 4 — CONTEXTUAL:
  Psychological momentum
  Historical patterns
  Trajectory intelligence
  Social sentiment (verified, multi-source)

LEVEL 5 — PLANNING ONLY:
  Scenario intelligence outputs
  Trajectory estimates
  Anticipatory signals
  Breaking news (unverified or single-source)
```

## The complete reasoning sequence

```
For any SportMind analysis follow this exact sequence:

 1. Load core/agent-onboarding.md
    Confirm mandatory file loading order.

 2. Assess macro environment:
    macro/macro-regulatory-sportfi.md
    macro/crypto-digital-asset-intelligence.md
    Is macro override active? If yes: HOLD — stop here.

 3. Confirm fan token state:
    fan-token/registry/complete-registry.md
    What state is this token in?
    Apply state-dependent base modifier.

 4. Assess trajectory:
    core/trajectory-intelligence.md
    Is there a 6+ month trajectory signal?
    Apply trajectory modifier if confirmed.

 5. Build scenario map:
    core/scenario-intelligence.md
    What are the 2-4 key scenarios for this analysis?

 6. Apply sport domain signal:
    sports/[relevant sport].md
    Calculate base adjusted score.

 7. Apply athlete intelligence:
    athlete/[relevant file].md
    Apply availability and position modifiers.

 8. Apply situational modifiers:
    core/venue-intelligence.md
    core/weather-intelligence.md
    core/referee-intelligence.md
    core/psychological-intelligence.md
    core/coaching-intelligence.md

 9. Check for breaking news:
    core/breaking-news-intelligence.md
    Any unresolved breaking signals?
    Apply confidence decay framework.

10. Assess signal confidence:
    core/signal-confidence-framework.md
    What is the overall confidence level?
    HOLD conditions met? If yes: HOLD.

11. Calculate FTP PATH_2 if applicable:
    fan-token/ftp-path2.md
    Is this an FTP PATH_2 token? ($AFC only as of May 2026)
    Calculate pre-liquidation pool.
    Apply WIN probability from steps 6-8.

12. Produce scenario-weighted output:
    Show full scenario map.
    Show probability-weighted summary.
    Include confidence level and resolution trigger.

13. Post-match (after event fires):
    core/post-match-intelligence.md
    Update form, supply, and modifiers.
    Prepare for next fixture.
```

## Context — the situational frame

```
Context is the third dimension of SportMind alongside intelligence and reasoning.
It is the situational awareness that determines which intelligence is relevant
and how reasoning should be weighted in this specific scenario.

Context has three layers:

────────────────────────────────────────

MACRO CONTEXT:
  What is the current state of the world that all signals sit within?
  · Crypto cycle phase
  · Regulatory jurisdiction status
  · Institutional environment
  · Ecosystem health score

  This does not change match-to-match. It changes over weeks and months.
  Always load macro context first.

────────────────────────────────────────

EVENT CONTEXT:
  What is the specific situation this analysis is for?
  · Which competition and stage
  · Which teams or athletes
  · Which fan tokens are affected
  · What is the stakes level
  · What is the timing relative to key events
    (UCL Final, World Cup, transfer window)

  Event context determines which sport domain file, which athlete file,
  and which tournament modifier applies.

────────────────────────────────────────

SIGNAL CONTEXT:
  What signals have already fired that this analysis must account for?
  · Recent results and form
  · Breaking news not yet confirmed
  · Pending regulatory decisions
  · Pre-liquidation windows open
  · Governance votes active

  Signal context is carried forward from core/smi-digest.md —
  the accumulated intelligence state.

────────────────────────────────────────

CONTEXT FAILURE:
  The most common agent reasoning error is applying correct intelligence
  and correct reasoning in the wrong context.

  EXAMPLE 1 — wrong token context:
    Applying the FTP PATH_2 burn framework to $BAR which is demand-only.
    The intelligence and reasoning are correct.
    The context (wrong token) makes the output wrong.

  EXAMPLE 2 — wrong macro context:
    Applying a bull market demand modifier during a confirmed bear phase.
    The modifier value is correct.
    The macro context makes it wrong.

  Context check = the first step in every SportMind analysis.
  Always confirm context before applying intelligence and reasoning.
```

## Intelligence accumulation principle

```
Intelligence does not reset between fixtures. It accumulates.

Every new analysis starts with the full context of everything
SportMind has learned — form signals, supply changes, psychological
modifiers, press conference intelligence, regulatory developments.

The post-match intelligence from the previous fixture feeds directly
into the pre-match intelligence for the next fixture:
  Form signal (decayed appropriately)
  FTP PATH_2 pool (updated with any burns or mints)
  Psychological modifier (carried from post-match narrative)
  Injury revelations (updated athlete intelligence)
  Tactical intelligence (manager signals from press conference)

A sport domain signal of 72.4 means something different:
  In a bull macro environment versus a bear macro environment.
  For a club on a 12-month ascending trajectory versus descending.
  For a token in its first month versus after 18 months of community data.

This is why the loading order in core/agent-onboarding.md begins with
core/smi-digest.md — the digest carries the accumulated intelligence
state forward so every new analysis starts complete.

The reasoning sequence in this file is not a checklist.
It is a representation of how context, intelligence, and reasoning
accumulate into a signal that is more than the sum of its parts.
```
