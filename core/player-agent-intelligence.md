# Player Agent Intelligence

**How to reason about agent and contract signals as leading indicators.**
Agent activity precedes official announcements by weeks or months — it is one of
SportMind's most reliable early-warning signals.

---

## Agent activity as leading indicator

```
AGENT ACTIVITY SIGNAL FRAMEWORK:

  Public appearances with rival club officials:
    HIGH transfer probability signal.
    Apply: ×1.25 departure probability modifier.

  Agent commenting on player future publicly:
    Transfer process is active — not idle speculation.
    Apply: ×1.20 departure probability modifier.
    If agent uses specific language about "next step" or "new challenge":
    Upgrade to ×1.30.

  Agent silence after renewal rumours:
    Negotiation stalled — not progressing.
    Apply: ×1.15 departure probability modifier.
    Rationale: active renewals generate communication; silence signals impasse.

  Agent publicly praising current club:
    Renewal more likely — positive framing.
    Apply: ×0.85 departure probability modifier.

  Agent travelling to a specific city:
    If confirmed by Tier 1 source: credible directional signal.
    Apply: ×1.20 probability weight to that destination.

INTERPRETATION RULE:
  Agent signals are leading indicators — not confirmations.
  Apply source tier to all agent signals (see core/breaking-news-intelligence.md).
  Anonymous agent source: ×0.50 weight.
  Named agent, Tier 1 journalist: ×0.80 weight.
  Agent statement direct (Tier 1 source): ×0.90 weight.
```

## Contract expiry framework

```
24+ MONTHS REMAINING:
  Status: LOW immediate transfer risk.
  Player is an asset, not a liability.
  Apply: standard demand modifiers — no contract discount.
  CDI: unaffected.

12-24 MONTHS REMAINING:
  Status: ELEVATED transfer speculation window.
  Club faces commercial decision: sell now or risk losing for free.
  Apply: ×1.08 departure probability modifier.
  Fan token demand: apply ×0.97 uncertainty discount (mild).
  Rationale: speculation begins, renewal not yet urgent.

UNDER 12 MONTHS REMAINING:
  Status: HIGH transfer probability if no renewal agreed.
  Apply: ×1.20 departure probability modifier.
  Fan token demand: apply ×0.94 uncertainty discount.
  Replacement quality uncertainty now a demand signal.

UNDER 6 MONTHS REMAINING:
  Status: MAXIMUM departure signal.
  Free transfer window opens January 1 — no transfer fee required.
  Apply: ×1.35 departure probability modifier.
  Fan token demand shifts: from player quality to replacement quality signal.
  Monitor: has the club identified or signed a replacement?
    Replacement signed: ×0.97 demand (succession confirmed, uncertainty reduced)
    No replacement visible: ×0.90 demand (structural gap looming)

CONTRACT EXPIRED (free agent):
  Apply: full departure signal to old club.
  New club demand: ×1.10 premium for new signing narrative (14-day duration).
  If key position for old club: apply star departure framework from
    core/star-departure-intelligence.md.

CONTRACT RENEWAL CONFIRMED:
  Apply: ×1.06 demand stability signal.
  Duration: 2-3 weeks then normalise.
  If long-term (3+ years): ×1.08 sustained.
```

## Agent network intelligence

```
SAME AGENT AS PREVIOUS SIGNING:
  If a player shares an agent with a player recently signed by a specific club:
  Apply: ×1.15 probability weight to that destination.
  Rationale: agent loyalty and relationship routing create pipeline patterns.

AGENT WITH KNOWN CLUB RELATIONSHIPS:
  If a Tier 1 source documents an agent's strong relationship with a specific club:
  Apply: probability weighting to clubs in that agent's network.
  Do not invent agent-club relationships from inference alone.

AGENT CHANGE SIGNAL:
  Player switching agents is often a precursor to a major career move.
  Apply: ×1.10 general transfer probability within 6 months of confirmed agent change.
  Rationale: players change agents when they are unhappy with career direction
    or when a move is being prepared that requires specialist representation.

SUPER-AGENT SIGNAL:
  Certain agents manage large portfolios of players across specific clubs or leagues.
  When a super-agent is confirmed to represent a player:
  Transfer probability to clubs in that agent's portfolio is elevated.
  Apply: ×1.12 to clubs where the agent already has represented players.

AGENT CONFLICT SIGNAL:
  Agent publicly criticising club management or contract offer:
  Apply: ×1.30 departure probability — agent is escalating publicly.
  This is the strongest agent departure signal short of a formal transfer request.
```

## Fan token demand connection

```
KEY PLAYER ENTERING FINAL 12 MONTHS:
  Apply: ×0.94 uncertainty discount to demand baseline.
  Duration: until renewal or departure is confirmed.
  If the player is in the top-3 fan engagement drivers for the club:
  Upgrade discount to ×0.90.

KEY PLAYER RENEWS CONTRACT:
  Apply: ×1.06 stability signal.
  Duration: 2-3 weeks then normalise.
  Long-term renewal (3+ years): ×1.08 sustained.

FAILED RENEWAL — PLAYER DEPARTS:
  Apply full star departure framework.
  Reference: core/star-departure-intelligence.md
  The CDI impact of a star departure compounds if the player was a fan token ambassador:
    Ambassador departs: ×0.85 CDI sustained (brand identity loss)
    Standard departure: standard star departure modifier

SPECULATIVE TRANSFER (unconfirmed):
  Apply ×0.96 uncertainty modifier while speculation is unresolved.
  This is mild — do not over-discount on unconfirmed signals.
  Resolution:
    Transfer confirmed: apply departure modifier in full.
    Transfer denied: remove discount, return to baseline.
    No resolution after 72 hours: maintain mild discount until resolved.

AGENT ACTIVITY DURING FAN TOKEN GOVERNANCE WINDOW:
  If agent activity fires during an active governance vote:
  Holder uncertainty may suppress vote participation.
  Apply: ×0.90 governance participation weight if key player departure is active signal.
```
