## How to get on this leaderboard

See [FIRST-RECORD-CHALLENGE.md](../FIRST-RECORD-CHALLENGE.md) for the full process.

The short version:
1. Run SportMind before a real match — get a DIRECTION and CONFIDENCE level
2. Submit as a timestamped GitHub issue before kickoff
3. Add the result after the match

Wrong predictions are as valuable as correct ones.
