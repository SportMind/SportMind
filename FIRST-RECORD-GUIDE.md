# First Record Challenge — Getting Started

No coding required. No experience needed.
Just a prediction before a match and a result after.

---

## What you need

- A free Claude account: [claude.ai](https://claude.ai)
- A free GitHub account: [github.com](https://github.com)
- About 10 minutes across two sittings

---

## Step 1 — Before the match: get the prediction

1. Go to [sportmind.dev/first-record/](https://sportmind.dev/first-record/)
2. Copy the SportMind system prompt (clearly marked on the page)
3. Paste it into a new Claude chat
4. Type: `"Run SportMind pre-match analysis for [Team A] vs [Team B], [Competition], [Date]"`
5. Screenshot or copy the output — you will see a DIRECTION and CONFIDENCE level

---

## Step 2 — Submit before kickoff

1. Go to [github.com/SportMind/SportMind](https://github.com/SportMind/SportMind)
2. Click **Issues → New issue**
3. Title: `Calibration Record — [Team A] vs [Team B] — [Date]`
4. Paste the prediction output and the match details
5. Click **Submit** — this timestamps your prediction before the match

---

## Step 3 — After the match

1. Find your issue on GitHub
2. Add a comment with the actual result
3. Note whether the direction was correct or incorrect

That is it. Your record is complete.
