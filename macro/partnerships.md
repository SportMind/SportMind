## CHILIZ CHAIN WALLET ACCESS — THREE-MODEL ARCHITECTURE

Fan Tokens on Chiliz Chain are accessible via three confirmed
wallet infrastructure models. Agents reasoning about holder
security, onboarding friction, or custody architecture should
load this framework.

```
MODEL 1 — CUSTODIAL (Socios Wallet)
  Provider: Socios.com native wallet
  Custody: fully custodial — Socios holds keys
  User experience: lowest friction, app-native
  Security model: platform trust, no self-custody
  Best for: mainstream fan onboarding, first-time holders
  Relevant signals: Socios platform activity, Tier 2 → Tier 1 conversion

MODEL 2 — STANDARD SELF-CUSTODY (MetaMask, Trust Wallet, etc.)
  Provider: third-party non-custodial wallets
  Custody: user holds seed phrase / private key
  User experience: moderate friction — seed phrase management required
  Security model: single point of failure at seed phrase
  Best for: crypto-native holders, DeFi participants
  Relevant signals: on-chain activity, DEX volume, LP participation

MODEL 3 — MPC WALLET (Multi-Party Computation)
  Provider: MPC-architecture wallets (confirmed available for Chiliz Chain)
  Custody: distributed key computation — no single point of failure
  User experience: keyless recovery — no seed phrase required
  Security model: mathematically distributed key shares, no seed phrase
    vulnerability, zero-hack architecture (confirmed track record)
  Geographic reach: US, EU, Asia, Africa — multi-region confirmed
  Best for: security-conscious holders, institutional-adjacent users,
    onboarding segments with high seed phrase loss risk

Agent rule: MPC wallet access is now confirmed as a structural
  option alongside Socios Wallet and standard self-custody.
  When reasoning about holder security risk or onboarding architecture,
  apply the correct model — each carries different security tradeoffs.

MPC NOTE FOR LIBRARY LONGEVITY:
  "MPC wallet" encodes the structural architecture, not a specific
  provider. This framework remains valid regardless of which MPC
  wallet providers are active at any given time.
```
